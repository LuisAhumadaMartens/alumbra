\namespace umbra
Umbra, Alumbra's portable C++ engine.

\namespace umbra::base
Umbra's base library: the installed error catalogue, error details and URL redaction.

The threading primitives and the Abseil-based status helpers of this library are internal and not installed; see
[threading](https://github.com/LuisAhumadaMartens/alumbra/blob/main/docs/architecture/threading.md) and
[errors](https://github.com/LuisAhumadaMartens/alumbra/blob/main/docs/architecture/errors.md).
